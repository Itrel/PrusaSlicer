# Full Plate Brim / `brim_clip`

This document describes the intended behavior and a low-risk implementation strategy for the **Full Plate Brim** feature.

The feature adds a new configuration flag, `brim_clip`, whose primary purpose is:

1. **Constrain outer brim toolpaths to the printable bed area** (no brim segments may be generated outside the build plate outline).

Additionally, a procedural **bed-edge “frame”** may be used as a geometric constraint. With the refined requirements below, the frame is considered to lie in the **unprintable region immediately outside** the printable bed outline.

The bed outline may be rectangular, circular, convex, or fully custom (arbitrary polygon).

---

## Current brim pipeline (relevant parts)

In `src/libslic3r/Brim.cpp` (`make_brim()`):

- Outer brim is generated by expanding “islands” (object bottom contours offset by brim separation) and building loops.
- Those loops are then **clipped** using:

```cpp
intersection_pl(..., islands_area)
```

where `islands_area` is derived from `islands_area_ex = top_level_outer_brim_area(...)`.

**Implication:** the authoritative constraint for outer brim placement is `islands_area`.

---

## Final requirements (refined)

### Bed outline / printable area
- Must use the **actual printable bed outline** (not a bounding box).
- Must work for round beds and arbitrary bed shapes.

### Constrain outer brim
- When `brim_clip` is enabled, **outer brim must never extend outside the printable area**.

### Refined edge-case behavior: object perimeter on bed boundary
- If an object’s outer perimeter lies on (or crosses) the bed boundary, any outer brim segments that would fall outside the printable area must not be generated.
- In particular, the first outer brim loop “outward” from such an object is inherently outside the printable area and must be clipped away.

### Frame concept (refined)
- The “frame” is modeled as a narrow band **outside** the printable area, immediately adjacent to the bed boundary.
- Because the frame lies in unprintable space, it is not intended to be printed as an extrusion; it exists to define the geometric constraint boundary.
- As a consequence, it is no longer necessary to conditionally emit frame extrusion based on whether outer brim touches it; the constraint is enforced by clipping the brim to the printable area.

### Robustness
- Boolean ops must remain stable in the presence of coincident edges (object perimeter exactly at bed boundary).

---

## Implementation plan (minimal and local to `Brim.cpp`)

The implementation is designed to minimize churn:

- **No synthetic `PrintObject` is created.**
- `src/libslic3r/Brim.hpp` remains unchanged.
- The feature is implemented by injecting bed-derived polygons into the existing brim flow to constrain `islands_area_ex`.

### 1) Obtain the printable bed polygon

Use the printer bed shape polygon directly.

The core source of truth is `PrintConfig::bed_shape` (unscaled) and `BuildVolume` (which uses the same input to build a scaled bed polygon).

`src/libslic3r/BuildVolume.cpp` builds the polygon using:

```cpp
m_polygon = Polygon::new_scale(bed_shape);
```

In `Brim.cpp` we can reconstruct the same scaled polygon locally (low coupling) from the config bed shape:

- `Polygon bed_poly = Polygon::new_scale(print.config().bed_shape.values);`

This guarantees support for arbitrary bed outlines.

### 2) Hard-clip outer brim to printable outline (`brim_clip`)

Immediately after:

- `islands_area_ex = top_level_outer_brim_area(...)`

apply:

- `islands_area_ex = intersection_ex(islands_area_ex, bed_ex_clip)`

where:

- `bed_ex = { ExPolygon(bed_poly) }`
- `bed_ex_clip = offset_ex(bed_ex, -SCALED_EPSILON, ...)`

The small inward epsilon keeps boolean ops robust in the edge case where object perimeters align exactly with the bed boundary.

After clipping, regenerate:

- `islands_area = to_polygons(islands_area_ex)`

so the existing

```cpp
intersection_pl(..., islands_area)
```

automatically removes any would-be brim segments outside the printable area.

### 3) Optional “unprintable frame band” geometry

If needed for debugging or for future constraint logic, define an explicit unprintable band outside the bed boundary:

- `outer = offset_ex(bed_ex, +frame_thickness, ...)`
- `frame_unprintable = diff_ex(outer, bed_ex)`

This represents the unprintable space just outside the bed.

Under the refined requirements, this geometry is **not emitted as extrusion**. Its role is conceptual/diagnostic: anything intersecting this band is, by definition, outside printable area and must be clipped away.

### 4) No frame extrusion under refined requirements

Since the “frame” resides in unprintable space, any toolpaths lying in that region must not be printed.

Therefore:
- Do not generate frame brim toolpaths.
- Do not attempt to conditionally emit frame toolpaths.
- Rely on the bed-clipped `islands_area` to enforce the constraint.

---

## Configuration surface

- `brim_clip` (bool): enables bed clipping for brim generation.

If additional parameters are desired (for diagnostics), they should not change the fundamental invariant:

> Brim toolpaths must be a subset of the printable bed polygon.

---

## Notes / rationale

- Clipping `islands_area_ex` to the printable bed polygon is the simplest and most reliable way to guarantee no outer brim is generated outside the printable region.
- The refined “frame is outside printable area” model naturally handles the case where a model sits exactly on the bed boundary: outward brim loops fall outside and are clipped away.
- Avoiding frame extrusion eliminates the need to compute when/where the frame should be printed.
